# DataMind Agent 完整演示流程

页面地址均为本机 `http://127.0.0.1:8000`。预置业务、图纸与审批记录均为演示材料。

> **开箱即可问答。** 本包已在 `data/model_config.env` 中预置一个评测用的 DeepSeek 接入（模型 `deepseek-flash`），因此「路线 B」不需要你配置任何东西就能直接演示三条问答链路。
>
> 若该预置密钥被吊销、超额或网络不通，改走「路线 A」：知识图谱、图纸与尺寸、字段复核、文件解析完全不依赖模型，照样能完整演示。也可以在网页「模型接入」换成你自己的模型。

## 前提：启动服务

完成 Docker Desktop 首次设置，完整解压演示包。Windows 双击 `run.bat`，Mac 双击 `run.command`，等待就绪并打开首页。停止用 `stop.bat` / `stop.command`，数据会保留。

## 路线 A：零配置演示（不需要密钥、不联网）

### A1. 查看知识图谱

打开[知识图谱](http://127.0.0.1:8000/#/wiki)，查看“演示零件 A200”“演示指标：外径”“演示流程：独立尺寸审批”三篇发布词条、两条关系。通过词条目录选中并点“打开详情”。内容来自人工模板，**未调用模型**；发布不代表事实已核验。

### A2. 查看图纸与尺寸

打开[图纸与实体](http://127.0.0.1:8000/#/governance?tab=cad)，选 `demo-cad-a200`，查看 A200 / CAD-DEV-1 / R2、预览、标注和关联复核。打开[尺寸核验](http://127.0.0.1:8000/#/governance?tab=dimensions)，点绑定 `demo-dimension-a200`，查看测量 `dimension-demo-1` 与独立批准链，在“对照历史”点“回放”。结果：**20.04 mm 在 [19.9, 20.1] mm 内**，只说明这条标注比较。

### A3. 查看字段复核与独立审批

打开[字段复核](http://127.0.0.1:8000/#/governance?tab=fields)，选“工业合成演示：工艺与质检原文”，展开已有审批的字段，核对原文定位、复核人与另一位审批人的记录。审批不改变原文或自动裁定来源冲突。

### A4. 上传并解析文件

打开[我的文件](http://127.0.0.1:8000/#/files)，选择下方原生 PDF，来源声明选合成演示，等待解析并查看解析、复核、可检索三种状态。解析用的是随包的离线 OCR / 公式权重，**同样不需要模型密钥**。**解析成功或复核批准不等于自动建立问答索引**，通用上传索引步骤仍为 deferred。后台处理器未运行时查看启动日志。

## 路线 B：自然语言问答（已预置模型，开箱即用）

### B1. 模型接入（默认已经配好）

本包预置了评测用的 DeepSeek 接入，**直接进入 B2 提问即可**。打开[模型接入](http://127.0.0.1:8000/#/model)可以看到当前配置来源为环境配置。

想换成自己的模型：点“新建配置”，填写协议、接口地址、模型名和自己的 API 密钥，点“保存并启用”，再点“测试连接”。网页中保存并启用的配置**优先于**预置文件。使用宿主机模型可用 `http://host.docker.internal:端口/v1`。

预置密钥仅用于本次评测演示，**请勿外传**；如被吊销、额度耗尽或网络不通，页面会明确提示具体原因（「模型服务拒绝了该 API 密钥」「上游模型账户额度不足」「无法连接模型服务」等），此时按「路线 A」演示不受影响，或填入你自己的模型。

### B2. 完成三条问答链路

打开[问数与问答](http://127.0.0.1:8000/#/app)，点击对应建议问题；快捷问题会切换范围。手工输入时先选择下表范围。

   | 顺序与范围 | 输入问题 | 展示重点 |
   | --- | --- | --- |
   | 零售问数 | 2025年销售额最高的前三个产品是什么？ | SQL、结果表、前三个产品及销售额 |
   | 文档问答 | 七天无理由退款的条件是什么？ | 制度原文引用与来源信息，核对回答是否有据 |
   | 工业温度核验 | 2026年9月A102工序30哪些批次温度超限？生产记录和质检报告是否一致？ | 生产测量、工艺区间、报告原值、单位与版本差异 |

   范围分别对应零售库、`demo_kb`、工业库与 `industrial_demo`。工业核验为限定合成场景，冲突、待复核和拒答都应如实展示。

### B3. 查看执行与证据

在工作台切换“证据轨迹”，点击节点；回到对话展开“思考过程”查看实际事件。打开[运行记录](http://127.0.0.1:8000/#/runs)，点击刚才的问题查看 ID、状态与回答，或点“打开该会话”。初始包没有历史问答。
